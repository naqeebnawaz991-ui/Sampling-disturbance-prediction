# Soil Sampling Disturbance Streamlit App

This version is intentionally a **deployment-only front-end** for the outputs generated by your own strengthened research pipeline.

It does **not** retrain XGBoost, retune hyperparameters, rerun LOSO/CV, recompute the applicability-domain thresholds, or add a new applicability criterion.

## Files used directly from your research pipeline

Required:

- `best_model.joblib`
- `applicability_domain.xlsx`

Optional but displayed when available:

- `best_model_summary.xlsx`
- `reproducibility_settings.xlsx`
- `software_versions.json`
- `best_model_parameters.json`

## Recommended folder structure

```text
soil_disturbance_streamlit_app/
├── app.py
├── requirements.txt
└── pipeline_outputs/
    ├── best_model.joblib
    ├── applicability_domain.xlsx
    ├── best_model_summary.xlsx
    ├── reproducibility_settings.xlsx
    ├── software_versions.json
    └── best_model_parameters.json
```

You can simply copy these files from the timestamped `Results_...` folder created by the research pipeline into `pipeline_outputs/`.

Alternatively, if you run `streamlit run app.py` from a directory containing the timestamped `Results_*` folder, the app will automatically use the newest compatible results folder.

## Applicability-domain implementation

The app reproduces the criteria exported by the research pipeline:

1. observed predictor min–max range,
2. robust 1st–99th percentile range,
3. standardized Euclidean multivariate distance,
4. combined AD = robust 1st–99th percentile criterion **AND** multivariate 95th-percentile criterion.

The threshold and all predictor summary statistics are read directly from `applicability_domain.xlsx`; the app does not derive them from the raw CSV.

## SHAP

Local SHAP values are calculated for each new input using `shap.TreeExplainer` applied to the exact saved `best_model.joblib`. This is an explanation step only; it does not change or refit the model.

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
